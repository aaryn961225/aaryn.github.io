使用方式

1. 將整個 frontend 資料夾複製到 aaryn961225.github.io 專案根目錄。
2. 確認路徑為：
   aaryn961225.github.io/frontend/index.html
3. 在專案根目錄執行：
   git add frontend
   git commit -m "Add front-end visualization portfolio"
   git push origin main
4. 等待 GitHub Pages 部署後開啟：
   https://aaryn961225.github.io/frontend/

此頁使用相對路徑連結現有作品：
- ../projects/ui-charts/
- ../projects/dog/views/case-3d.html
- ../projects/automation/playwright-report/
- ../projects/automation/RUN_GUIDE.html
- ../（原 QA 主作品集）

若未來調整現有作品資料夾名稱，請同步修改 frontend/index.html 中對應的 href。
