# Source Examples

此資料夾保留 `chart38.zip` 中的 38 組來源圖表案例，另含一份重複備份 `chart14 copy.html`。

## 使用範圍

- 用於追溯早期 `menu_demo.html` 與圖表選單概念的來源。
- 主作品頁未宣稱所有來源案例均已重新工程化。
- `projects/ui-charts/index.html` 重新整合 8 個可離線執行的代表性 ECharts：Line、Area、Bar、Stacked Bar、Donut、Radar、Gauge、Scatter。

## 原始案例限制

多數原始 HTML 使用 `/include/` 絕對路徑、RequireJS、jQuery 或不同版本的 ECharts；部分案例可能另需 ECharts GL。因此本資料夾僅作為來源參考，不是面試現場的主要執行入口。
