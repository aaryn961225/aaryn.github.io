# Integration Roadmap

## Current v8
- Playwright black-box UI automation is executable.
- Specification Quality Gate is rule-based and executable.
- Prompt Library is prepared.
- JSON contracts are prepared.
- Deterministic mock LLM, MCP, and n8n adapters are executable.
- Docker runtime configuration files are prepared.

## Future Phase 1+
- Install Docker Desktop in an approved environment.
- Build and verify the QA automation runtime image on an approved Docker host.
- Run Playwright in isolated headless mode.

## Future Phase 2
- Replace mock LLM adapter with approved local or hosted LLM.
- Replace mock MCP context builder with real MCP server integration.
- Replace mock n8n payload with approved webhook delivery.
- Keep human review as a mandatory gate.
