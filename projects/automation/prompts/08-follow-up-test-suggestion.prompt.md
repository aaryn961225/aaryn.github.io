# 08 Follow-up Test Suggestion Prompt

## Purpose
Suggest follow-up tests after reviewing specification and test results.

## Input
- Quality Gate report
- Test summary
- Current specs and tasks

## Output
- Suggested new tests
- Priority
- Reason
- Required clarification, if any

## Rules
- Do not directly create or enable tests without QA approval.
- Suggestions must map back to a spec section or a clarification item.
