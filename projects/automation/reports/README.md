# Reports

Generated and retained demonstration outputs are stored in this folder.

## Common Files

- `quality-gate-report.json` — Specification Quality Gate result
- `test-summary.json` — generated or sample Playwright summary
- `mcp-context.json` — generated by `npm.cmd run context:build`
- `ai-review.json` and `ai-review.md` — generated by `npm.cmd run ai:mock`
- `n8n-payload.json` and `mock-notification.md` — generated by `npm.cmd run n8n:mock`

These artifacts are designed to contain sanitized demonstration data rather than application source code or credentials. Review generated files before sharing them outside the local environment.
